Fast NFC para Android

Instala el lector de Fast para cobrar acercando una tarjeta o un móvil a tu teléfono. El cobro se inicia desde Fast y se confirma con Stripe.

Descargar Fast NFC 1.0.1

  1. Abre este enlace en tu teléfono e instala el archivo de Fast NFC. Android puede pedirte autorizar esta instalación.
  2. Activa NFC y mantén Android actualizado. El cobro real exige desactivar las Opciones de desarrollador.
  3. En Fast abre Cobrar o una factura pendiente y elige Cobrar por NFC.
  4. Abre el lector y permite la ubicación precisa que pide Stripe. Comprueba el importe antes de acercar la tarjeta.

Si una operación se interrumpe, comprueba ese mismo cobro. La factura puede emitirse antes o después del pago.
